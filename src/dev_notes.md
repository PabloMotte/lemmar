# Developer notes

## Using

- [Python](https://docs.python.org/3/) Python 3.13
- [UV](https://docs.astral.sh/uv/) - for general Python project utility and ease
- [click](https://click.palletsprojects.com/en/stable/) - for command-line argument parsing
- [Using UV to build and install Python CLI apps](https://mathspp.com/blog/using-uv-to-build-and-install-python-cli-apps)
- [Python Packaging User Guide](https://packaging.python.org/en/latest/overview/)
- [PyInstaller](https://pyinstaller.org/en/stable/) - to freeze the app for distribution

## Install notes

Use UV to install the app on the local (development) PC:

- uv tool install . -e
